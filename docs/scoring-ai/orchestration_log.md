# ScoringAI 야간 작업 로그 (오케스트레이션)

> 대주제: **관광지 여행 난이도를 객관적 지표로 수치화한다.**
> 시작: 2026-11-03 새벽 · 브랜치 `JANENAMMMM/scoring-ai`

## 종료 기준 (모두 충족하면 중단)

1. **대상 확정**: 다낭권 관광지 15곳 목록 + 좌표·식별자 (`data/scoring/attractions.json`)
2. **객관 지표 수집**: 관광지별로 사람 판단 없이 재현 가능한 측정값을 최소 3개 차원 이상 확보 (예: OSM 내부 보행로 길이, 계단 구간 수/길이, 고도 범위, 대체 이동수단 유무, 실외 비율·기후)
3. **보조 신호**: 리뷰 기반 신호(Tripadvisor 비율, Google 주제 언급 수, Reddit)를 같은 관광지에 대해 수집
4. **산정 엔진**: `src/scoring/`에 측정값 → 차원 점수 → 상·중·하 규칙 엔진 + 테스트 통과
5. **검증**: 객관 지표와 리뷰 신호의 순위 상관, 차원별 결측률, 민감도(기준값 ±20%에서 등급 변동) 보고서
6. **문서**: 최종 설계안 v1.0 + 결과 보고(팀 공유용 요약 1장)
